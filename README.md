# Profile Details App (React Native) – 37149

Mini Project 01 for SE303.3 Mobile Application Development, NSBM Green University.

**Student:** Sachintha Dilshan Daluwaththage
**Index number:** 37149

The app shows a "My Profile" screen with an avatar, name, student ID, email, university and a points counter. Tap the floating **+** button to add a point.

## Run

```bash
npm install
npx expo start
```

Then press `a` for Android, `i` for iOS, or `w` for web, or scan the QR code with Expo Go.

The profile details are in `src/profile.js`.
